# WebIt

Minimal project foundation for the WebIt software brand. This is not the complete website; the initial shell intentionally contains only the approved brand lockup while the logo and base project setup are reviewed.

## Stack

- React
- Vite
- TypeScript
- Plain CSS with centralized custom properties (Tailwind is not needed for this minimal foundation)

## Commands

```sh
npm install
npm run dev
npm run typecheck
npm run build
npm run preview
```

## Brand assets

See [`docs/brand-assets.md`](docs/brand-assets.md) for the source file, extraction method, limitations, and remaining approvals. The original reference remains preserved at `public/brand/webit-logo-reference.jpg`.

## Current scope

No landing page, product catalogue, testimonials, business claims, animations, backend, or analytics are included. Add those only after the corresponding scope and facts are approved.
